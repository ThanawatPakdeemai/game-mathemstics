# QuizMotion 🎮

เกมตอบคำถามแข่งความเร็วในห้องเรียน ใช้ได้ทุกวิชา (ไทย คณิต อังกฤษ วิทยาศาสตร์ ประวัติศาสตร์ วรรณกรรม ฯลฯ): คุณครูเปิดจอผ่านโปรเจคเตอร์ นักเรียนใช้มือถือสแกน QR-Code เข้าร่วมแบบ real-time (Socket.IO) ได้สูงสุด 50 คนต่อห้อง

- คลังโจทย์ในระบบตอนนี้มีเฉพาะคณิตศาสตร์ ม.4–6
- วิชาอื่น ๆ: ครูนำเข้าโจทย์ของตัวเอง (.json) บนหน้าตั้งค่าห้อง ใช้ได้เฉพาะห้องนั้น จบเกมแล้วต้องนำเข้าใหม่

## วิธีรัน

```bash
npm install

# โหมดพัฒนา (เซิร์ฟเวอร์ :3000 + หน้าเว็บ :5173)
npm run dev
# เปิดหน้าครูที่ http://localhost:5173

# โหมดใช้งานจริง (พอร์ตเดียว :3000)
npm run build
npm start
# เปิดหน้าครูที่ http://localhost:3000
```

- มือถือนักเรียนต้องต่อ **Wi-Fi เดียวกับเครื่องครู** — QR-Code จะใช้ IP ในวง LAN ของเครื่องให้อัตโนมัติ
- ลิงก์ที่ใช้ใน QR ตอน deploy ตั้งไว้ใน `.env.production` (`PUBLIC_URL` / `VITE_PUBLIC_URL` = https://xxxxx.com) — ไม่มีผลกับ `npm run dev`
- ถ้าเครื่องครูเปิด firewall ต้องอนุญาตพอร์ต 5173 (dev) หรือ 3000 (production)
- ทดสอบหลายผู้เล่นบนเครื่องเดียว: ใช้หน้าต่าง incognito/คนละเบราว์เซอร์ (แต่ละเบราว์เซอร์จำผู้เล่นไว้ 1 คน เพื่อให้กลับเข้าห้องเดิมได้เมื่อหลุด)

## Deploy (หน้าเว็บบน Vercel + เซิร์ฟเวอร์เกมแยก)

Vercel โฮสต์ได้เฉพาะหน้าเว็บ (static) — **รันเซิร์ฟเวอร์ Socket.IO ไม่ได้** จึงต้องแยกเป็น 2 ส่วน:

1. **เซิร์ฟเวอร์เกม** — deploy repo นี้บนบริการที่รัน Node ค้างไว้ได้ (Render / Railway / Fly.io)
   - Build: `npm install && npm run build` · Start: `npm start`
2. **หน้าเว็บ (Vercel)** — ใส่ URL ของเซิร์ฟเวอร์จากข้อ 1 ใน `.env.production`:
   ```
   VITE_SERVER_URL=https://your-game-server.onrender.com
   ```
   แล้ว deploy ใหม่ (`vercel.json` ตั้ง rewrite ไว้แล้ว ลิงก์ `/join/xxxxxx` จึงเปิดตรงได้)

หรือจะใช้แค่เซิร์ฟเวอร์จากข้อ 1 อย่างเดียวก็ได้ (มันเสิร์ฟหน้าเว็บด้วย) — ให้เปลี่ยน `PUBLIC_URL`/`VITE_PUBLIC_URL` เป็นโดเมนของเซิร์ฟเวอร์นั้นแทน

## โครงสร้าง

```
shared/constants.js        ค่าตั้งต้น: วิชา, ระดับชั้น/หมวด, ความยาก, เวลา, คะแนน, ผู้เล่นสูงสุด 50, จำนวนกด 100 ครั้ง
shared/questionSet.js      ตรวจสอบไฟล์โจทย์ (ใช้ทั้งคลังในระบบและไฟล์ที่ครูนำเข้า) + ไฟล์ตัวอย่าง
server/index.js            Express + Socket.IO (event ของครูและนักเรียน)
server/game.js             ตรรกะห้องเกม: lobby, ตัวจับเวลา (pause ได้), ให้คะแนน, สรุปผล
server/questionBank.js     โหลด/สุ่มโจทย์จากคลัง + เลือกโจทย์จากชุดที่ครูนำเข้า
server/data/questions/     คลังโจทย์ JSON (AI สร้าง): ม.4 เซต, ม.4 ตรรกศาสตร์, ม.5 ตรีโกณ, ม.6 ลำดับและอนุกรม
src/host/                  หน้าจอครู: ตั้งค่า → QR/ล็อบบี้ → นับถอยหลัง → โจทย์ → เฉลย → สรุปผล/Export
src/player/                หน้าจอนักเรียน: ชื่อ + เลือกตัวละคร → ตอบ → มินิเกมกด 100 ครั้ง → ผลคะแนน
racing-characters-15/      รูปตัวละครผู้เล่น 50 ตัว (ชื่อโฟลเดอร์เดิม)
schoolsubjects-characters/ รูปต้นฉบับตัวละครประจำวิชา → ย่อไว้ใช้บนเว็บที่ src/assets/subjects/*.webp
```

## นำเข้าโจทย์ของครู (ทุกวิชา)

หน้าตั้งค่าห้อง → ปุ่ม “นำเข้าโจทย์ (.json)” → ระบบตรวจไฟล์และแสดงสรุปก่อนใช้ ดาวน์โหลดไฟล์ตัวอย่างได้ในหน้าต่างเดียวกัน

```json
{
  "subject": "thai",
  "grade": "m2",
  "title": "คำราชาศัพท์",
  "author": "ชื่อครู",
  "questions": [
    {
      "difficulty": "easy",
      "question": "คำราชาศัพท์ของ \"กิน\" สำหรับพระมหากษัตริย์คือข้อใด",
      "choices": ["เสวย", "ฉัน", "รับประทาน", "ทาน"],
      "answer": 0,
      "explanation": "ไม่บังคับ"
    }
  ]
}
```

- `subject` (ไม่บังคับ): `thai` | `math` | `english` | `science` | `history` | `literature` | `other`
- `grade` (ไม่บังคับ): id ชั้นปี เช่น `m1`–`m6`, `v1`–`v3`, `b1` — ถ้าใส่ ระบบเลือกชั้นให้อัตโนมัติ
- สูงสุด 200 ข้อ/ไฟล์ ขนาดไม่เกิน 1 MB · เลือก “ทั้งชุด” เพื่อเล่นทุกข้อตามลำดับในไฟล์
- ไม่สลับลำดับตัวเลือกของชุดที่นำเข้า (ครูเขียนตัวเลือกแบบ “ถูกทั้ง ก และ ข” ได้)
- ชุดที่นำเข้าเก็บไว้ในห้องนั้นเท่านั้น ไม่เข้าคลังและไม่บันทึกลงดิสก์ของเซิร์ฟเวอร์

## เพิ่มโจทย์เข้าคลังในระบบ (รูปแบบ JSON)

วางไฟล์ `.json` ไว้ใน `server/data/questions/` แล้วรีสตาร์ทเซิร์ฟเวอร์ (ระบบรวมกับโจทย์เดิมให้อัตโนมัติ)

```json
{
  "grade": "m4",
  "topic": "sets",
  "title": "เซต",
  "questions": [
    {
      "id": "my-001",
      "difficulty": "easy",
      "question": "ให้ A = {1, 2} จำนวนสับเซตของ A คือ",
      "choices": ["2", "3", "4", "8"],
      "answer": 2,
      "explanation": "2² = 4"
    }
  ]
}
```

- `grade`: `m4` | `m5` | `m6`, `topic`: `sets` | `logic` | `trig` | `sequences`
- `difficulty`: `easy` | `medium` | `hard` | `veryhard`, `answer`: index ของคำตอบที่ถูก (0 = ก … 3 = ง)
- ระบบสลับลำดับตัวเลือกให้ทุกเกม
